# Okja — Asset Studio brief

**Status:** Okja is the fifth Asset Studio group. It is a **single-brand group**:
one masterbrand, four cafés, not four separate venue brands. The group has its
own wordmark, palette, typography, copy, arch motif and photography, and a
verified print path.

The source was the okja.com crawler output, not a supplied brand kit. There was
no brand guide, no token file and no vector wordmark master, so the pack below is
a **reconstruction** from the site's media, page copy and live CSS. It is usable
now; the items in §2 make it production-ready.

cafés. The alternative is four location cards (Camps Bay, Kloof, Liverpool,

directories with their own tokens.

## 4. Logo brief (for a designer, not AI)

- **Horizontal wordmark** — custom fat rounded lowercase `okja`, dot above the j.
  Use the site's five letterforms as reference; redraw as one vector with
  consistent spacing and a defined baseline. Do not set it in Intervogue Soft.
- **Stacked cup lockup** — `ok` over `ja.` with the smiley period. This is the
  cup/packaging cut. It needs its own vector master and clear space.
- **Favicon** — hot-pink square, yellow `ok`; simplify for 16 px.
- **Cafe icon** — yellow muffin/cake outline with `CAFE`; one-colour cut.
- **Shop icon** — yellow shop outline with `SHOP`; one-colour cut.
- **Colour cuts** — pink on cream; white on photography/deep blue; yellow on hot
  pink; ink on cream; navy on lemon. No outlines, gradients, shadows or effects.
- **Clear space** — the height of the j dot; minimum 24 mm / 80 px for the
  horizontal wordmark.
- **Files** — SVG (primary), AI/EPS/PDF; transparent; colour/ink/white.

## 6. How the group model works

- Every imported pack is a group. Okja is one brand, so its gate has one centred
  card; the four cafés are locations, not brand cards.
- The top-left group selector switches groups while working; the gate tabs do the
  same. The last brand used in each group is remembered.
- Saved assets record their group/brand and restore across groups.
- The same 25 hospitality layouts are reused; brand data, fonts, logos, photos
  and copy are substituted.
- Adding another group later is another pack import; the gate tabs and selector
  pick it up automatically.
