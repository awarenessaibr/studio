What runs where

The page talks to this Studio server. The server manages an optional MLX-Audio process on 127.0.0.1:8771; model weights stay in the existing Hugging Face cache.

What is honest

No speech server means no audio. The voice agent falls back to two curated directions when no local language model is available; it never invents a reference transcript.

What this is not

No WhatsApp/Drive/email connectors, auth, approvals, segmentation, transcription or embedding search in this increment. No freeform Asset Studio placement: audio is saved as a library content asset.
